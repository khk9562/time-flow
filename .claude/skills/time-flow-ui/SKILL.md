# 흐름 UI 규칙

이 프로젝트는 **모바일 우선**이다. 휴대폰 화면을 먼저 설계하고, 넓은 화면은 그 위에 덧붙인다.
작업 전에 `DESIGN.md` 를 읽고, 이미 있는 토큰(`src/tokens.stylex.ts`)과 공용 요소(`src/components/ui.tsx`, `src/components/Sheet.tsx`)를 먼저 쓴다.

## 1. 모바일 우선

- 기준 분기점은 `@media (max-width: 560px)` (코드에서는 `PHONE` 상수). 860px 은 두 단 → 한 단이 바뀌는 지점.
- 스타일은 휴대폰에서 바로 쓸 수 있게 짠다: 누르는 곳은 최소 44px (`@media (pointer: coarse)` 에서 키운다),
  글자 입력칸은 16px 이상이라 iOS 자동 확대가 없어야 한다.
- 손가락으로 누를 수 없을 만큼 작은 요소(예: 365개의 점)에 "눌러서 이동" 같은 동작을 걸지 않는다.
  대신 훑기(스크럽)나 아래쪽 상세 영역으로 정보를 보여 준다.
- 키보드가 올라오면 `useKeyboardInset` / `useKeepFocusVisible` 로 입력칸이 가려지지 않게 한다.
- 가로 넘기기(`useSwipe`)가 있는 화면에서 손짓을 받는 요소에는 `NO_SWIPE` 를 붙인다.
- 넓은 화면 확인은 마지막에 한다. 휴대폰(390×844)과 데스크톱(1280×900) 스크린샷을 둘 다 확인한다.

## 2. 떠 있는 UI = 바텀시트 / 드로어

알림(`alert`)이나 예/아니오만 묻는 단순 확인(`confirm`)이 **아닌** 떠 있는 UI는 전부 `Sheet` 로 띄운다.
팝오버, 드롭다운 메뉴, 가운데 팝업 모달, 선택 목록, 상세 보기, 설정 패널 모두 해당된다.

- 휴대폰: 아래에서 올라오는 **바텀시트**. 손잡이·머리를 끌어 내리면 손가락을 따라오고, 충분히 내리면 닫힌다.
- PC 분기점(561px 이상): 오른쪽에서 밀려 들어오는 **드로어**.
- 사용법:
  ```tsx
  import { Sheet, sheetItem } from './Sheet';
  <Sheet open={open} onClose={() => setOpen(false)} title="제목" subtitle="한 줄 설명">
    {items.map((it, i) => (
      <button {...stylex.props(myItem, sheetItem.enter)} style={{ animationDelay: `${120 + i * 60}ms` }} />
    ))}
  </Sheet>
  ```
- `Sheet` 가 이미 해 주는 것: 포털로 띄우기, 배경 어둡게, Esc·바깥 누르기로 닫기, 첫 버튼에 초점,
  닫히면 연 버튼으로 초점 되돌리기, 닫힐 때도 움직임(사라지는 동안 남겨 두기). 새로 만들지 말고 이것을 쓴다.
- 여는 버튼에는 `aria-haspopup="dialog"` 와 `aria-expanded` 를 단다.
- 위치를 계산해 요소 옆에 붙는 팝오버(`position: absolute` 메뉴)는 만들지 않는다.
- 예외: 지울지 한 번 더 묻는 정도의 확인은 버튼 자리에서 바로 바꾸는 인라인 확인(예: YearPage 의 "지울까요?")으로 처리해도 된다.

## 3. 모든 UI는 유려하게 움직인다

- 나타날 때·사라질 때·상태가 바뀔 때 모두 움직임이 있어야 한다. 갑자기 생기거나 사라지는 요소를 두지 않는다.
- 이징은 토큰만 쓴다: 들어오기 `ease.out`, 오가기 `ease.inOut`, 튕기는 작은 반응 `ease.spring`.
  시간은 `dur.tap`(140) / `dur.quick`(260) / 들어오기 400~520ms / 사라지기 260~300ms (사라짐이 더 짧다).
- 목록은 차례로 떠오른다(항목마다 50~70ms 지연). 숫자는 세어 올라가고, 막대·채움은 길이가 자라난다.
- 누름 반응: `transform: scale(0.92~0.98)` on `:active`.
- 등장 애니메이션이 `transform` 을 쥐고 있는 요소는 나중의 확대·끌기를 `scale` / `translate` 개별 속성으로 한다
  (같은 `transform` 을 덮어쓰면 애니메이션이 다시 시작되거나 무시된다).
- `prefers-reduced-motion` 을 존중한다 (`reducedMotion()` in `src/lib/canvas.ts`).

## 4. 생김새

- 무채색: 색은 사용자가 긋는 형광펜(`PEN_COLORS`)에만 있다. UI는 `color.*` 토큰(잉크 농담)만 쓴다.
- 스타일은 StyleX(`stylex.create`), 색·크기는 `src/tokens.stylex.ts` 토큰. 임의 색 값을 새로 만들지 않는다.
- 문구는 한국어, 짧고 다정한 존댓말("~해요", "~입니다"). 이모티콘 없음.
- 데이터 시각화는 휴대폰 폭에서 먼저 읽혀야 한다: 범례를 붙이고, 숫자 요약을 그림 위에 두고,
  눌러서/훑어서 보는 상세는 그림 아래 고정된 영역에 보여 준다(떠 있는 툴팁 대신).

## 5. 끝내기 전에

- `npm run build` 통과.
- `?demo` 로 띄워 휴대폰·데스크톱 스크린샷 확인 (`?t=2026-11-15T14:00:00` 로 시각 고정 가능).
- 새로 정한 규칙이 있으면 `DESIGN.md` 에 적는다.
